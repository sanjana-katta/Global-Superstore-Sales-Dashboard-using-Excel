# 📊 Global Superstore Sales Analysis

An end-to-end **Data Analytics Project** built using **Excel, SQL (MySQL), and Power BI** to analyze sales performance, customer behavior, and business profitability using the Global Superstore dataset.

This project demonstrates the complete analytics workflow—from data cleaning and transformation to business analysis and interactive dashboard development.

---

# 📌 Project Overview

The objective of this project is to transform raw sales data into meaningful business insights through data analysis and visualization.

The project is divided into three stages:

* 📈 Excel Dashboard
* 🗄️ SQL Business Analysis
* 📊 Power BI Interactive Dashboard

Each stage builds upon the previous one, showcasing different data analytics skills used in real-world business scenarios.
